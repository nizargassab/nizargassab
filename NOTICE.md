# Profile design references

The profile presentation adapts the structure and banner composition of
[walidbosso/walidbosso](https://github.com/walidbosso/walidbosso), licensed under
Apache-2.0. The license is preserved in LICENSE-walidbosso.txt.

Modified for Nizar Gassab: header likeness and text, introduction, contact links,
skills, project cards, profile statistics and contribution visualizations.
No education, certificates, account rankings or personal statistics belonging to
the reference author are presented as Nizar's.

The shared coding GIFs are embedded from the same public GitHub user-attachment
URLs as the reference. Shields.io provides the service and technology badges.
All statistics widgets in assets/generated are rendered from Nizar's GitHub data
by scripts/update_profile.py. No private repository names or source code are used.
